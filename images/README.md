# Imágenes pendientes

Coloca aquí las siguientes imágenes (mismo nombre) para que la web las muestre correctamente:

- `hero.jpg` – imagen de fondo grande para la cabecera (trufa/bosque)
- `nosotros.jpg` – imagen para la sección "Nosotros"
- `calidad.jpg` – imagen para la sección "Calidad"
- `trufa-negra.jpg`, `trufa-verano.jpg`, `trufa-blanca.jpg`, `aceite-trufa.jpg`, `trufa-conserva.jpg` – imágenes de cada producto

Formato recomendado: JPG/WebP optimizado, mínimo 1200px de ancho para el hero y 600px para el resto.
